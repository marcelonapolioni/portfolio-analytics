# Portfolio Analytics

Este projeto e um portfolio estatico para publicacao de estudos de caso profissionais via GitHub Pages.

O objetivo e reunir projetos de Business Intelligence, Engenharia de Dados, Processos de TI e Governanca Operacional em paginas simples, organizadas e faceis de evoluir.

## Estrutura inicial

- `index.html`: pagina inicial do portfolio.
- `css/styles.css`: estilos globais do site.
- `cases/`: paginas dos estudos de caso.
- `assets/`: imagens, PDFs e outros arquivos estaticos.
- `PROJECT_BRIEF.md`: objetivo, escopo e restricoes do projeto.

## Publicacao no GitHub Pages

1. Crie um repositorio no GitHub.
2. Envie os arquivos deste projeto para o repositorio.
3. No GitHub, acesse `Settings`.
4. Abra a secao `Pages`.
5. Em `Build and deployment`, selecione a branch principal do repositorio.
6. Escolha a pasta raiz do projeto como origem da publicacao.
7. Salve a configuracao e aguarde o GitHub gerar a URL publica.

Como este site e composto apenas por HTML, CSS e arquivos estaticos, nao e necessario instalar dependencias ou executar processos de build.
