# Portfólio Analytics

Este projeto é um portfólio estático para publicação de estudos de caso profissionais via GitHub Pages.

O objetivo é reunir projetos de Business Intelligence, Engenharia de Dados, Processos de TI e Governança Operacional em páginas simples, organizadas e fáceis de evoluir.

## Estrutura inicial

- `index.html`: página inicial do portfólio.
- `css/styles.css`: estilos globais do site.
- `cases/`: páginas dos estudos de caso.
- `assets/`: imagens, PDFs e outros arquivos estáticos.
- `PROJECT_BRIEF.md`: objetivo, escopo e restrições do projeto.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos deste projeto para o repositório.
3. No GitHub, acesse `Settings`.
4. Abra a seção `Pages`.
5. Em `Build and deployment`, selecione a branch principal do repositório.
6. Escolha a pasta raiz do projeto como origem da publicação.
7. Salve a configuração e aguarde o GitHub gerar a URL pública.

Como este site é composto apenas por HTML, CSS e arquivos estáticos, não é necessário instalar dependências ou executar processos de build.
