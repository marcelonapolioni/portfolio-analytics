# Project Brief

## Objetivo

Criar um portfolio estatico para publicar estudos de caso profissionais relacionados a Business Intelligence, Engenharia de Dados, Processos de TI e Governanca Operacional.

O projeto deve servir como uma base limpa e organizada para evoluir narrativas tecnicas, diagnosticos, indicadores, evidencias analiticas e materiais complementares.

## Escopo inicial

- Pagina inicial do portfolio.
- Estrutura para estudos de caso.
- Pagina placeholder para o case `Diagnostico operacional de TI`.
- Pasta para ativos estaticos, como imagens, diagramas e PDFs.
- Estilo simples, responsivo e profissional.

## Restricoes importantes

- Nao expor nome de empresa.
- Nao expor nomes de pessoas.
- Nao expor sistemas internos.
- Nao inventar metricas.
- Preservar anonimizacao.
- Usar dados sinteticos ou generalizados quando necessario.

## Diretrizes de conteudo

Todo estudo de caso deve priorizar clareza, responsabilidade e rastreabilidade. Quando houver dados sensiveis, eles devem ser removidos, anonimizados, agregados ou substituidos por dados sinteticos antes da publicacao.
